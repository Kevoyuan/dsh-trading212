# 方向文档 — Cartographer（dsh × Trading 212 新一代仪表盘）

> 这是相对现有「Lumen」系统的新一轮视觉与信息架构提案，代号 **Cartographer**——像一份地图：克制、清晰、能让人一眼看出「我在哪儿、地图上还有什么、要往哪儿走」。

---

## 1. 对现状的诊断（度量覆盖不到的 UX 层面）

现有 Lumen 系统在度量维度（对比度、溢出、重叠、字号）上 0 失败，但第一眼仍存在几个实质问题：

| 问题 | 表现 | 影响 |
| --- | --- | --- |
| **顶部真空** | 浮动岛顶栏与下方内容之间存在 ~60px 不可控留白；首屏 (1440×900) 中，左侧账户卡从 y≈140 才出现 | 用户视线落点空转，第一信息比图表晚出现 |
| **同一信息三处展示** | 「投资组合」mosaic + 「投资组合」列表流 + 「主要持仓」表格，三处位置、同一数据、不同形态 | 阅读疲劳、信任消耗（同一组数字三种说法） |
| **图表埋在画布中部** | AAPL 价格曲线 + 买卖成交点出现在首屏 60% 之后 | 用户最关心「我现在多少钱、走势如何」的回答离视野太远 |
| **持仓明细用右对齐 key-value 矩阵** | 像一张收据：标签左、数值右、一行一行 | 大脑要纵向跳跃拼装一只股票的全貌 |
| **强调色与容器色同色相** | 蓝色强调 + 浅蓝背景 + 蓝色装饰渐变 | 没有「焦点」与「背景」之分，所有元素都「想被看到」 |
| **首屏折叠内容多** | 1440×900 首屏只能看到账户 + 主账户 + 部分 mosaic + 部分 chart 顶 | 关键 KPI 被切到第二屏 |

---

## 2. 设计原则（Cartographer）

1. **一张地图，而不是一个房间。** 单层结构，所有关键 KPI 横向排在顶部，任何一屏都能回答「我现在多少钱」「我最近赚赔了多少」「我有哪些持仓」。
2. **一份事实。** 持仓信息只在一处出现：左侧排序列表。图表画布跟随选中项切换。
3. **暖中性，单一焦点。** 纸白底 + 深墨字 + 单一靛蓝焦点 + 财务语义色。无渐变、无投影堆叠。
4. **可触控。** 触控目标 ≥ 36px，悬停态不仅改色还改层级（1px 抬升）。
5. **数字服务于眼睛。** 数字列右对齐、等宽数字；标签左对齐；金额旁边始终紧跟币种与时间范围。
6. **一眼能懂。** 任何图标旁边都有文字标签；任何色彩都伴随方向符号（▲▼）以辅助色盲。

## 3. 视觉系统（token）

```css
/* —— 表面 —— 暖白三阶，从底到顶 */
--paper:    #F4F1EA;   /* 页面底 */
--card:     #FBFAF6;   /* 卡片 */
--well:     #ECE7DC;   /* 凹陷容器（如分割条、轨道） */

/* —— 墨 —— */
--ink-1: #15171A;      /* 标题、关键数字 */
--ink-2: #3F4651;      /* 正文 */
--ink-3: #6E7682;      /* 次要文字、标签 */
--hair:  #DAD3C5;      /* 唯一分割线颜色 */

/* —— 焦点 —— 仅一种靛蓝，用于选中、CTA、链接 */
--focus:    #2F4D7A;   /* 在 card 上 5.4:1 */
--focus-soft:#E3E9F1;

/* —— 财务语义色（≥4.5:1 在 paper 与 card 上） */
--pos:  #166534;
--pos-soft:#E1EFE5;
--neg:  #B03325;
--neg-soft:#F7E6E2;

/* —— 字号 5 级，最小 12px —— */
--t-12: 12px;  --t-13: 13px;  --t-15: 15px;
--t-18: 18px;  --t-24: 24px;  --t-36: 36px;

/* —— 圆角 —— */
--r-1: 6px;  --r-2: 12px;  --r-3: 20px;  --r-pill: 999px;

/* —— 单一阴影（卡片层），纸感 —— */
--sh-1: 0 1px 0 rgba(20,30,50,.04), 0 6px 14px -10px rgba(20,30,50,.10);

/* —— 运动 —— */
--ease: cubic-bezier(.32,.72,0,1);
--d-1: 140ms;  --d-2: 260ms;

/* —— 间距 —— */
--s-1: 4px; --s-2: 8px; --s-3: 12px; --s-4: 16px;
--s-5: 24px; --s-6: 32px; --s-7: 48px;
```

**深色主题** 不复制一切——只覆盖：底、卡、井、墨三阶、聚焦、阴阳色、头发线、阴影。

## 4. 信息架构变化（与 Lumen 对比，以及与 T212 官网的对位）

| 原 Lumen | Cartographer | 与 T212 官网对位 |
| --- | --- | --- |
| 浮动岛顶栏（孤悬于内容之外） | 顶部命令栏（贴顶融入内容，52px） | T212 顶栏 60px —— 简化图标 |
| 左侧「folio」列：账户 → 现金 → 投资组合流 → 投资组合 mosaic | **左列三块卡**（账户卡 + KPI 网格 + 持仓列表），全部以卡片形态堆叠，与右侧画布对齐 | **同 T212**：账户值卡 + mini chart + 列表 全部在左 |
| 投资组合 mosaic（5 块） | **取消**——同一信息已在左列持仓列表中表达 | T212 没有 mosaic，由 Investments 列表替代 |
| 投资组合列表流（5 行带圆环 logo） | **保留并强化**：左列底部持仓卡片，权重排序 + sparkline + 收益 | 同 T212 的 Investments |
| 右侧画布：资产头 + 图表 + 持仓明细（5 行 KV）+ P/L 贡献 + 币种暴露 + 主要持仓表 | **右侧画布**：资产头 + 大图表 + 三宫格详情（持仓 / 关键指标 / 待处理订单） | T212：Your investment + pending order + AutoInvest —— 我们读只读，故只到 pending order |
| 5 处描述同一组持仓 | **1 处** | |

「主要持仓」表折叠为左列持仓列表的可展开行；点击列表/项，右侧画布切换资产。

### 4.1 账户卡（左列顶部）结构

```
┌─────────────────────────────────┐
│ 账户总价值 · EUR           [⚙]  │
│ €24,382.61 EUR                  │
│ ▲ +€302.30 (+1.4%) 今日          │
│ [mini line chart — 90px 高]     │
│ 可用现金 €2,115.40 | 本周 +€128 │
└─────────────────────────────────┘
```

mini chart 由 `analytics.dailySnapshots` 驱动；不可得时降级为只显示「本周回报」一行。

### 4.2 KPI 网格（左列中部）

2 列 × 3 行 紧凑卡片，hairline 分隔：
- 投资市值 / 已实现盈亏
- 持仓成本 / 汇兑影响
- 现金占比（前三大）/ 持仓数（待处理）

每个 cell 12px 标签 + 15px 数值 + 12px 副行；高度 ~64px。

## 5. 关键界面

### 5.1 顶部全局账户条（Summary bar）
粘性，1440 高 96px / 移动 132px。内部 6 个分组：
- 账户总值（36px 主数字 + 币种 + 今日盈亏）
- 现金（€2,115.40 + Pie 内现金副行）
- 投资市值 / 持仓成本
- 已实现盈亏 / 汇兑影响
- 上下文（持仓数 / 现金占比 / 前三大集中度）
- 待处理订单 chip（仅当有）

### 5.2 左侧排序列表
- 表头：排序选择（权重 / 收益 / 名称）+ 「按市场」筛选
- 每行 56px：圆角 logo + 名称 + ticker · 货币 + sparkline（64×24）+ 权重 + 市值 + 收益（含 ▲▼）

### 5.3 右侧资产画布
- **资产头**：圆角 logo + ticker + 名称 + 主价格（36px）+ 区间内涨跌 + 范围切换器（1D/1W/1M/3M/6M/1Y/5Y）
- **图表卡**：aspect-ratio 4:1，最小 380px 高。买卖点保持上箭头（绿）/ 下箭头（琥珀），轴标签 12px 等宽
- **三宫格详情**：
  - 「持仓明细」 5 行键值（每项含图标）
  - 「关键指标」 4 项（区间波动、回撤、贡献度、汇率影响）
  - 「待处理订单」 列表（无则显示空态插画与说明）

### 5.4 命令栏
48px 高，浅底深字，底部一根头发线。从左到右：品牌 + 账户徽章（DEMO/LIVE）| 视图 tabs（概览/持仓/历史/设置/帮助）| 搜索（占位）| 主题/隐私/刷新。

### 5.5 持仓详情页（`?view=holdings` / 点导航「持仓」）

右列画布与概览互斥切换。结构自上而下：

```
持仓总额
€22,267.21 EUR
──────────────────────────────────────
累计回报                  +€2,336.33 (+11.72%)
持仓成本                          €19,930.88
──────────────────────────────────────
持仓  5                            [↕ 排序]
[ 市值 ][ 市场价 ]      ← 分段控件，选中态实底焦点色
显示每只持仓的当前市值、权重与累计回报…
──────────────────────────────────────
ⓐ  Apple Inc.      24.4%   €5,428.10
   AAPL · USD              +€840.60 (+18.3%)
ⓝ  NVIDIA Corp.    26.3%   €5,860.25
   …
```

规则：
- 金额与收益率**右对齐**、等宽数字；名称左对齐；权重居中偏右。
- 圆形 logo 40px（`--r-pill` 全圆），与左列的圆角方形 logo 区分——圆形专用于"资产"语境。
- 点击任意一行 → 回到概览画布并选中该标的。
- 只读约束：无 Buy/Sell 按钮，无撤单 ×。

## 6. 可用性守则

1. **所有数字带语境**：旁边必有币种、时间范围或单位。
2. **可访问性**：键盘导航完整、对比度 ≥ 4.5:1、`prefers-reduced-motion` 关闭所有过渡。
3. **隐私遮罩**：点击眼睛按钮，所有金额淡入淡出到统一 `••••` 形态，文字颜色一并降低。
4. **暗色模式**：底 `#15171A`、卡 `#1E2127`、墨三阶同步翻转。强调色由靛蓝转稍亮的 `#7B9DD9`。
5. **空/错/无连接状态**：同一组态词汇——插画 + 一句话说明 + 一个动作。

## 6.1 图表：用真库，不画假的

原型的价格图表由 **TradingView Lightweight Charts v5.2.1** 渲染，与生产
`src/app/App.tsx` 的 `PriceHistoryChart` **同一套配置**：

| 配置项 | 值 | 来源 |
| --- | --- | --- |
| `autoSize` | `true` | 生产同 |
| `layout.background` | `transparent` | 生产同 |
| `layout.textColor` | `--ink-3` | token |
| `layout.fontFamily` | `--font-mono` | token |
| `layout.fontSize` | `12` | token 下限 |
| `layout.attributionLogo` | `true` | **Lightweight Charts 许可要求** |
| `grid.horzLines.color` | `--hair` @ 0.75 | token |
| `grid.vertLines` | 不可见 | 生产同 |
| `crosshair.mode` | `Magnet` | 生产同 |
| `crosshair.*Line` | `--focus` @ 0.6，虚线 | token |
| `rightPriceScale.scaleMargins` | `top .12 / bottom .14` | 生产同 |
| `timeScale` | `fixLeftEdge` + `fixRightEdge`、`rightOffset 1`、`minBarSpacing .4` | 生产同 |
| 系列 | `LineSeries`，`lineWidth 2`，虚线 `priceLine` | 生产同 |
| 成交点 | `createSeriesMarkers`，买 ↑ 绿 / 卖 ↓ 琥珀 | 生产同 |

**为什么必须用真库**：轴刻度密度、十字光标吸附、缩放平移边界、成交点与 K 线的
时间对齐、canvas 字体栈、以及归属标记——这些都不是手绘 SVG 能验证的。手绘版
曾把成交点画在凭空假设的坐标上，无法证明"买卖点落在正确的时间位置"。

**颜色全部读 token**（`getComputedStyle(document.documentElement)`），不引入第二套调色板。
切换主题时重建图表，让 canvas 重新读取 token。

本地加载，不走 CDN（`../node_modules/lightweight-charts/dist/...standalone.production.js`），
符合品牌规范"no webfonts, no CDN, no new runtime dependency"。

## 7. 不做的事

- 不放任何装饰渐变。
- 不放超过 2 个层级阴影。
- 不引入衬线 display 字体。
- 不在 12px 以下用任何文字。
- 不让"想被看到"的东西用同一种颜色——焦点色只属于交互与选中。
